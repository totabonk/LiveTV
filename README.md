# World TV — Android TV + Phone

نسخة أولى احترافية من تطبيق مشاهدة القنوات.

المزايا:
- واجهة داكنة مناسبة للتلفاز والهاتف.
- بحث.
- تصنيف حسب النوع.
- المفضلة.
- مشغل Media3/ExoPlayer.
- دعم Android TV وAndroid Phone.

## إضافة القنوات
افتح:
`app/src/main/java/com/worldtv/app/MainActivity.kt`

وعدّل قائمة `channels`.

ضع فقط روابط بث تملك حق استخدامها أو لديك ترخيص لإعادة بثها.

## الإعلانات
هذه النسخة لا تضع إعلانات تلقائيًا. يمكن إضافة نظام إعلانات لاحقًا بعد تحديد مزود إعلانات متوافق مع الهاتف والتلفاز وسياسات المنصة.

## البناء
افتح المجلد في Android Studio ثم Run.
